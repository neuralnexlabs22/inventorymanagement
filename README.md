# Inventory Management System

A production-ready Stock & Inventory Management System built with Next.js, TypeScript, Tailwind CSS, and Drizzle ORM.

## Features

- Product Management
- Category Management
- Inward Stock
- Outward Stock
- Stock Ledger
- Inventory Valuation
- Low Stock Alerts
- Reports
- Responsive UI

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Drizzle ORM
- PostgreSQL (Supabase Ready)
